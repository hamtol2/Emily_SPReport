# 커머셜 공급 점검 리포트

폴더 상위의 `Commercial_Supply_Report.html`을 Chrome 또는 Edge로 열면 바로 사용할 수 있습니다. 별도 설치나 인터넷 연결은 필요하지 않습니다.

## 매주 갱신

1. Excel에서 새 원본 파일의 수식을 계산하고 저장합니다.
2. 리포트 오른쪽 위 **새 엑셀 불러오기**에서 `.xlsm` 또는 `.xlsx` 파일을 선택합니다.
3. 기간, 카테고리, FL1을 선택하고 월별 부족 / 신제품 / EOL 탭을 확인합니다. FL1은 원본 Family 1 열입니다.
4. **HTML 저장**을 누르면 새 데이터와 현재 조회 조건을 담은 리포트가 다운로드됩니다. 이 HTML 한 파일로 공유할 수 있습니다.

불러온 파일은 브라우저 안에서 처리하며, 매크로를 실행하거나 원본 파일을 변경하지 않습니다. 브라우저를 닫기 전에 HTML 저장을 눌러야 갱신 결과가 보존됩니다. CSV는 해당 표의 전체 검색 결과를 내보냅니다. 인쇄는 현재 탭의 전체 검색 결과를 사용합니다.

## 읽는 방법

- 기본 기간은 원본 월별 Q’ty 블록의 첫 3개월입니다. 현재 파일은 2024년 2~4월입니다.
- 부족: 원본에 저장된 월말 예상재고가 0 미만인 제품입니다. 실제 품절, 납품 가능 수량, 확정 발주 필요량과 구분합니다.
- 월별 부족수량은 월말 예상재고가 음수인 경우 그 절댓값을 양수로 표시합니다. 부족이 없는 달은 —로 표시합니다. 여러 달에 같은 부족 잔량이 이어질 수 있으므로 기간 전체를 단순 합산하지 않습니다.
- 카테고리별 부족수량 그래프와 부족수량 요약은 선택 종료월 기준입니다. 같은 월의 SKU별 부족 잔량을 합산하며, 카테고리 및 FL1 필터를 적용합니다.
- 제품명 클릭: 기초재고, 입고, 행사·일반 판매계획, 월말재고, 원본 셀, 제품 상태, 신·구제품 연결을 확인합니다.
- 제품 단계: Company Status를 우선 적용합니다. General과 코드가 다른 제품은 상태 차이로 표시합니다. TBD는 출시 준비, Canceled 표시는 취소 대상으로 분리합니다.
- 신·구 SKU 연결표의 모든 제품을 신제품으로 분류하지 않습니다. Final confirm date는 출시·EOL일이 아닙니다. 신제품 탭의 출시 월은 원본 전체 계획에서 처음 수요가 잡힌 월을 사용한 추정값이며 확정 출시일은 아닙니다.
- 수량은 원본 Q’ty 단위 그대로이며 Reporting Q’TY 환산은 적용하지 않습니다. 채널은 대상 설명이며 채널별 수량 배정이 아닙니다.
- 저장된 수식 결과가 없거나 헤더 구조가 달라지면 원본 확인이 필요합니다. 동일 SKU가 중복되면 불러오기를 중단합니다.

## 구현 및 확인

`build_report.py`는 상위 폴더의 가장 최근 수정 엑셀을 선택해 HTML을 생성합니다. 파일 경로를 인자로 지정할 수도 있습니다. Python 표준 라이브러리만 사용합니다. `template.html`, `style.css`, `app.js`가 리포트 소스입니다. 일반 사용자는 HTML 파일만 있으면 됩니다.

`verify_report.py`와 `verify_report.mjs`는 원본을 읽기 전용으로 대조하는 검증 도구입니다. 현재 파일의 677 SKU, 12개월 부족 SKU 수·수량을 독립 계산과 대조했습니다. 브라우저에서 엑셀 불러오기, 검색, 카테고리·제품 단계 필터, 상세, HTML 저장도 확인했습니다.
